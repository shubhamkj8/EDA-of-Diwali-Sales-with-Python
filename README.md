# EDA-of-Diwali-Sales Using Python | Pandas | NumPy | Matplotlib | Seaborn
# Overview

This project performs Exploratory Data Analysis (EDA) on Diwali sales data using Python to understand customer purchasing behavior, demographic trends, regional sales performance, and product demand patterns during the festive season.

The objective is to identify high-value customer segments and derive actionable business insights that can help improve targeted marketing, inventory planning, and sales strategies.

# Final Conclusion

The analysis reveals that married women aged 26–35 years from Uttar Pradesh, Maharashtra, and Karnataka working in IT, Healthcare, and Aviation sectors are the most valuable customer segment. These customers are more likely to purchase products from the Food, Clothing, and Electronics categories during the Diwali season.

By focusing inventory planning, targeted marketing, and promotional campaigns on these customer groups, businesses can significantly improve festive-season sales and customer engagement.
